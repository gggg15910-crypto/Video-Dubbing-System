# مترجم AI — تطبيق أندرويد أولي

واجهة عربية لاختيار فيديو وتحديد لغة المصدر واللغة المستهدفة. هذه النسخة لا تنفذ الدبلجة بعد.

## البناء
من AndroidIDE أو Android Studio افتح مجلد `android-app` ثم نفّذ Gradle Sync و `assembleDebug`.

## إنشاء APK من GitHub
بعد دمج هذه الملفات في الفرع الرئيسي، افتح تبويب Actions وشغّل **Build Android APK**. نزّل الناتج من Artifacts باسم `MutarjimAI-debug-apk`.

## الخطوة المتبقية
ربط الواجهة بخادم Dubby عبر API: رفع الفيديو، تشغيل التفريغ والترجمة وتوليد الصوت ومزامنته، ثم إرجاع رابط ملف MP4. لا تُدخل مفاتيح API داخل التطبيق؛ تحفظ على الخادم.
